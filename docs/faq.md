# FAQ

## 検索結果が表示されません

入力内容を変えて再検索してください。通信に失敗した場合は、画面に「検索に失敗しました」と表示されます。通信環境を確認してから、もう一度お試しください。

## 登録した場所が地図に表示されません

ホーム画面に表示されるのは、登録した場所の都道府県です。場所の登録が完了していることと、表示中のアカウントが正しいことを確認してください。

## 別の人の履歴を見たいです

アカウント画面で「選択中のアカウント」を切り替えてください。アカウントごとに訪れた場所が分けて保存されます。

## アカウントを削除するとどうなりますか？

削除したアカウントの訪れた場所も削除されます。必要な履歴が残っていないことを確認してから削除してください。
